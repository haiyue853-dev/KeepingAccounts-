# Corporate Clean 视觉版本

参考用户提供的 `corporate-clean-hard-prompt.md`，在原有记账应用结构中使用 blue-600 主按钮、slate-50 页面底色、白色卡片、gray-200 细边框与轻阴影。现有页面结构、文字内容、控件尺寸、记账和资产数据逻辑保持原样；图标保留其识别用途。

该参考文件以 Tailwind 和网站为例。项目使用 React Native：颜色、卡片边框与阴影落实在共享样式中；Web 增加 150ms 悬停、按下缩放和蓝色键盘焦点环，并支持系统的减少动态效果设置。原生端保留已有触摸反馈。
