# 自定义资产账户

用户已选择：各账户填写当前余额，直接相加；银行卡按银行区分并显示图标。

- 资产页顶部显示总资产，下方显示账户卡片和添加入口。金额按分保存与求和，不再叠加交易收支。
- 支持微信、支付宝、现金、具体银行及自定义账户；银行使用彩色银行文字徽标，其他账户使用本地图标，不依赖联网图片。
- 同一银行可有多个独立账户，自定义名称区分工资卡、储蓄卡等。不需要输入完整卡号。
- 新增、修改账户使用页内编辑区；名称用系统键盘，金额用记账风格计算键盘。支持四则运算、清空、退格、负数、两位小数和保存。取消不写入。
- 支持删除确认；保存失败保留编辑内容。空账户显示添加引导，加载失败可重试。
- SQLite 新增 asset_accounts 表。首次使用时，如已有起始余额，将旧页面的剩余金额迁入一个「原有资产」账户；用户可编辑或删除后分配。迁移标志与迁移账户同事务提交；之后删除所有账户也不重复迁入。
- 现有账本、收支和报销记录不改动。只迁移一次旧计算结果，此后资产与记账独立。
- 验证：金额精度、四则运算、异常输入、实际 SQLite CRUD 与迁移、应用 TypeScript 检查及 Web 页面交互。
