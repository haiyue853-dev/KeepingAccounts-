# v1.3.2 — 自定义资产账户与界面更新

这次更新将资产管理改为按账户记录当前余额，并调整了记账页面和整体界面。Android 安装包版本为 **1.3.2（versionCode 132）**。

## 更新内容

- **资产账户**：分别添加银行卡、微信、支付宝、现金等账户；同一家银行也可建立多个账户。账户提供对应标识，余额可用加减乘除键盘填写，总资产为所有账户当前余额之和。旧版起始余额在首次进入资产管理时迁移为「原有资产」账户；此后记账不会自动改变账户余额。
- **个人资料**：「我的」页面支持选择并保存头像。
- **界面**：采用浅蓝色 Corporate Clean 风格，统一分类选中态、排行榜图标和头部层次，应用图标改为货币标识。
- **修复**：日历日期格随页面宽度缩放；记账键盘按实际内容高度展开，避免底部按键在 Web 端被裁切，同时保留 Android 虚拟按键安全区处理。

## 安装与数据

下载下方的 `KeepingAccounts-v1.3.2.apk` 安装。同包名、同签名的旧版可直接覆盖安装，**不要先卸载旧版**，卸载会删除应用本地数据。本次 APK 使用项目现有的本地 Android Debug 签名；若旧版由其他签名构建，Android 会拒绝覆盖安装。

当前应用内的 JSON 导出只包含账本、分类和交易记录，**不包含资产账户、预算和头像**，不能把它当作这些数据的完整备份。
