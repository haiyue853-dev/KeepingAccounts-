# v1.3.3 — 资产账户自动计算与滑动日期

本次更新让资产账户从用户确认余额的当天开始自动计算，并改进记账日期选择及 Android 启动画面。应用内版本和 Android 安装包版本均为 **1.3.3（versionCode 133）**。

## 更新内容

- **资产自动计算**：先核对各账户余额，再在资产管理中点击「从今天开始计算」。当前余额作为期初余额；此前的记账不会追溯扣除。启用后记账时选择银行卡、微信等账户，收入和支出计入对应账户。手动修改余额会记录为一次校正。
- **关联记录**：语音记账、JSON/CSV 导入及返现、报销、退款记录可指定资产账户；编辑或删除关联记录后，账户余额按现有记录重新计算。
- **日期选择**：记账时可上下滑动年、月、日，松手后对齐到最近的日期，仍限制未来日期。
- **界面与启动**：更新蓝底人民币图标；Android 启动时显示应用 Logo 后进入首页。优化资产编辑键盘滚动、首页入口及图表页面的滚动和头部显示。

## 安装与数据

下载下方 `iSave-v1.3.3.apk`。安装后的应用名称也是 **iSave**。同包名、同签名的旧版可覆盖安装并保留本地数据，**不要先卸载旧版**。本次 APK 沿用项目的 Android Debug 签名；若旧版签名不同，Android 会拒绝覆盖安装。

当前 JSON 导出包含账本、分类和交易记录，**不包含资产账户、期初余额、预算和头像**。升级前如需完整备份，请保留原应用数据；不要把 JSON 导出当作完整备份。
